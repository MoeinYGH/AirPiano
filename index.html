How do I connect this to Wokwi?

1. Replace your sketch with sketch.ino (it adds one line: AP,<note>,<cm>,<brightness>).

2. The online wokwi.com page can't hand its serial output to another web page, so run the sim with the Wokwi VS Code extension (or Wokwi CLI) and use the bridge:

# Wokwi for VS Code — add to wokwi.toml, then start the simulation
[wokwi]
rfc2217ServerPort = 4000

# in this folder:
node bridge.js                       # reads rfc2217://localhost:4000

# or with the Wokwi CLI
wokwi-cli . | node bridge.js --stdin

3. Open http://localhost:8787 (the bridge serves this page) and click Wokwi bridge.

Real Arduino on USB instead? Click USB serial (Chrome / Edge). No hardware at all? Demo lets you play with the cursor.
